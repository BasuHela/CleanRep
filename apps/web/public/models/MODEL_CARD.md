# Pose model

MediaPipe PoseLandmarker Lite float16 version 1, used with tasks-vision 0.10.32. Exact download URL, hash and package version are in provenance.json; Apache 2.0 license is beside this file. The model is vendored and checked at build time. GPU then CPU fallback is implemented; real Nord 4 speed/accuracy has not been measured. This model estimates landmarks and does not provide clinical conclusions.
